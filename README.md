# TrustVote AI

**High-Integrity Decision Engine.** Infrastructure for transparent voting and AI-powered legislative analysis.

---

## Current Status

This project is in its **initial architecture phase**. I'm currently documenting the technical foundations and security protocols before any code implementation.

## Project Documentation

### Key Principles

- **Transparency:** Every technical decision is documented via ADRs (Architectural Decision Records).
- **Security First:** Zero-vulnerability policy for core dependencies.
- **Integrity:** Anchoring decisions and votes in an immutable infrastructure.
